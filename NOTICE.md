# Source and redistribution scope

This repository contains the article-specific material-point application.
The supplied GNU General Public License version 3 is preserved in LICENSE.
The application does not import or bundle the upstream JAX-FEM finite-element
tree. The software licence does not grant rights to independently supplied
datasets, original Fortran sources or source-paper images.

The implementation differentiates the selected admissible constitutive root
under the local regularity conditions described in the manuscript. Numerical
algorithms, material parameters and integration controls are retained from the
article implementation. SOURCE_MANIFEST.json records software hashes and the
reference source hashes. The corresponding numerical archive is preserved
separately with its original code and input signatures.

The repository excludes digitized literature coordinates, original Fortran,
manuscript PDFs and frozen-result payloads, including embedded observation
copies. Dataset and generated-output sharing terms are independent of the
software licence.
