# Source and redistribution scope

The software was extracted from the article-specific material-point application
in the existing numerical archive. The archive supplies GPL v3, which is
preserved verbatim. This repository does not bundle the upstream JAX-FEM
finite-element tree; the material-point application does not import it.

The corrected `_implicit_q0` documentation specifies the selected admissible
root and local implicit-derivative conditions. Its executable syntax is
unchanged from the frozen producer. `SOURCE_MANIFEST.json` retains both hashes
instead of rewriting historical numerical provenance.

The original archive explicitly records unresolved public redistribution terms
for digitized literature coordinates and the supplied Fortran sources. Those
files and all frozen-result payloads are excluded here, including embedded
observation copies. There are no source-paper images or manuscript PDFs in
this repository. The software licence does not grant rights to independently
supplied datasets or those excluded materials.

This is initially a private author-review repository. Making it public is a
separate step after author review. A private upload is not an archival DOI or
a claim that the article has been published.
